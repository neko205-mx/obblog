# 测试模式

## 启动与关闭

```bash
go run . -test
```

独立程序使用 `./bin/obblog -test`。部署面板可在启动命令添加 `-test`；需要同时保留正式服务时，使用不同监听端口，例如 `-test -addr 127.0.0.1:8090`。

每次创建 `os.TempDir()` 下独立的 `obblog-test-*` 目录，使用全新安装向导。`-data` 不参与测试模式，不读取、覆盖或删除已有安装。退出后这个测试安装不保留，下一次从头设置密码和知识库。

安装页、系统设置和后台顶部均提供“结束测试”。安装完成后需要登录才能结束；未安装时可直接结束。按钮停止服务并清理数据，当前页面转为空白页。单纯关闭浏览器标签不会停止服务器。Ctrl+C 和 SIGTERM（包括常规进程/容器停止）同样执行清理。端口占用等启动错误也会清理。

## 数据和 Git

选择普通服务器目录：复制程序支持的 Markdown、附件和目录结构到临时目录；隐藏路径、符号链接、Obsidian 配置与其他不支持文件不导入。编辑、发布只作用于副本。

选择已有 Git 仓库：复制笔记文件，为副本建立新的临时 Git 历史和本地 bare remote。原仓库工作树、提交和远端保持不变。Git 状态、提交、推送和拉取功能可用，但目标均为临时本地远端。

选择 GitHub 克隆：使用填写的凭据读取一次源仓库，然后提取笔记副本并建立临时本地 Git 仓库。后续不向 GitHub 推送，也不继续从原远端拉取；Token 不保存到测试配置。测试不同源版本时可重新导入。

选择空知识库：创建临时空目录，直接测试编辑、新建和发布。`-test -vault /path/to/source` 只预选服务器目录作为导入来源，密码仍在向导设置，不沿用环境变量密码。

退出顺序为停止接收请求、等待进行中的请求退出、关闭目录句柄、删除整个临时目录。配置、安装锁、密码摘要、正文与附件副本、测试 Git 工作树/远端及发布记录一起删除。服务内部状态同时清空，重复关闭不会误删其他目录。正常模式的关闭不删除持久数据。

测试会话使用独立的浏览器会话 Cookie，不替换正常后台 Cookie；从网页结束时使测试 Cookie 失效。测试模式不保存主题修改到 localStorage。

## 清理范围

这是应用数据清理，不是磁盘取证意义上的安全擦除。浏览器历史、密码管理器和外部日志不属于应用临时目录。SIGKILL（`kill -9`）、进程崩溃或断电不会运行 Go 的退出逻辑，可能留下系统临时目录；可通过文件管理器清理对应的 `obblog-test-*` 目录，不要删除仍在运行实例的目录。

## 测试

```bash
go test -race ./...
go vet ./...
```

覆盖关闭和重新开始安装、原始笔记/权限保持不变、Git 推送只进入临时远端、克隆后移除凭据、正常模式隔离、停止接口鉴权与跨站请求拒绝、关闭后请求不再创建目录、HTTP 服务取消/网页停止及监听失败清理。所有写入使用自动创建的临时目录与本地 Git 远端，不操作真实笔记库。

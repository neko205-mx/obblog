# 欢迎来到，你的知识花园。

这里不是另一个需要维护的内容平台。它只是你的笔记，换了一扇窗。

用熟悉的 **Obsidian** 记录，用 Git 保管，让那些值得反复阅读的想法，在浏览器里重新相遇。

> [!tip] 文件优先，思考自由
> 你的 Markdown 仍然是你的 Markdown。这个阅读器不会修改源文件，也不会向笔记库写入任何内容。

## 从一篇笔记开始

左侧是你的文件目录。展开文件夹，选择笔记，或者按下 `Ctrl / ⌘ + K` 搜索文件名称和路径。

- **像往常一样整理**：目录结构与你本地的笔记库一致。
- **沿着链接阅读**：打开 [[笔记/双向链接|双向链接]]，顺着一个想法走向另一个。
- **保持原始格式**：切换右上角的「源码」，查看未经改写的 Markdown。
- **随时重新读取**：点击文件浏览器上方的刷新按钮，读取本地最新文件。
- **看见知识的形状**：打开左侧 [[笔记/关系图谱|关系图谱]]，探索笔记之间的连接。

## 一处记录，多处阅读

笔记是内容的源头，浏览器默认是一个只读窗口。使用 `-write` 启动可显式开启本地编辑；目前不执行 Git 拉取、提交或推送，也不会发布你的笔记。

```text
Obsidian 笔记库
       │
       └── Go 只读服务
               ├── 文件浏览与搜索
               ├── Markdown 阅读
               └── 双链与附件访问
```

如果你想了解这个版本的能力与边界，可以阅读 [[笔记/使用指南]]。

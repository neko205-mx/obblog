# 使用指南

## 读取自己的笔记库

在项目目录运行以下命令，将路径替换为你的 Obsidian 仓库目录：

```bash
go run . -vault "/path/to/your/vault"
```

然后在浏览器打开 `http://127.0.0.1:8080`。

## 已支持的内容

| 类型 | 能力 |
| --- | --- |
| Markdown | 标题、列表、引用、表格、任务列表、代码块、脚注 |
| 内部链接 | 双链、显示别名、章节跳转、普通 Markdown 相对链接 |
| 附件 | 图片嵌入，PDF、音视频附件链接 |
| 属性 | YAML 原文折叠展示，源文件不变 |
| Callout | 基础提示块展示 |
| 关系图谱 | 全库/局部图、邻居深度、缩放拖动、类型筛选与节点跳转 |

## 当前边界

这个 MVP 默认只读，可以通过启动参数 `-write` 显式开启本地编辑和新建笔记。仍没有登录鉴权、公开发布和 Git 同步，保存不代表已提交或推送到 GitHub。关系图谱通过左侧图谱图标打开，也可以阅读 [[关系图谱]] 了解索引规则。

笔记嵌入 `![[其他笔记]]` 当前显示为可点击链接，不展开目标正文。块引用定位、数学公式、Mermaid 和 Canvas 暂未实现。

默认只监听本机。**不要将这个未加登录的阅读器直接暴露到公网读取私密笔记库**；它的所有访问者都能读取配置目录内的受支持文件。

## 更新本地内容

你可以继续通过已有的 Git 流程更新目录。之后点击左侧刷新按钮即可重新读取文件，不需要重启服务。

# 本地 Markdown 编辑 MVP

## 功能与启用

编辑默认可用，无需启动参数或设置开关。正常启动只需 `go run .`，浏览器完成密码和知识库设置。Web 安装入口见 [安装说明](installation.md)，下面命令仅演示兼容旧模式。

```bash
export OBBLOG_ADMIN_PASSWORD='replace-with-your-own-long-password'
go run . -vault "/path/to/temporary-vault" -addr 127.0.0.1:8091
```

编辑现有笔记或创建新笔记后，通过保存按钮或 Ctrl/Cmd+S 保存。支持源码行号、双链补全、基础格式插入、Tab/Shift+Tab 缩进、实时 Markdown 预览、窄屏预览切换和未保存状态。渲染和关系链接解析沿用现有 Go Markdown 实现，没有引入新的前端依赖。

笔记支持 `.md` 文件，新笔记只允许建在已经存在的目录。没有目录创建、重命名、删除、富文本编辑或语法高亮。

编辑器支持拖入图片、粘贴剪贴板图片或点击“图片”选择文件。图片保存在知识库根目录，自动在光标处插入 `![[文件名]]` 并显示预览；粘贴图片使用 `Pasted image 时间戳` 命名，同名文件自动加编号，不覆盖原文件。支持 PNG、JPEG、GIF、WebP、AVIF、SVG，单张最多 20 MiB，可一次插入多张。图片上传后即落盘，正文引用仍需保存；放弃草稿不会删除已上传的图片。

Git 模式上传图片同样校验远端及当前版本，上传后单独提交并推送图片，随后保存笔记使用更新后的 Git 版本。推送失败仍保留图片和引用并提示，可从 Git 管理重试；未上传的后续图片停止处理。

## 读写接口

| 接口 | 行为 |
| --- | --- |
| GET /api/vault | 返回文件树和 writable 能力标志 |
| GET /api/note?path=... | 返回原始 source 和内容 SHA-256 revision |
| PUT /api/note | 保存已有文件，必须提供 path、source、revision |
| POST /api/note | 新建文件，必须提供 path、source，不允许覆盖已有目标 |
| POST /api/preview | 仅渲染预览，不写文件，只读模式下也可用 |
| POST /api/asset | multipart/form-data，file 为图片，Git 模式还需 gitHead，返回实际 path 与新 Git 版本 |

笔记请求使用 JSON；正文必须明确提供字符串，缺省/null 不会被当成空文档写入。单篇正文仍限制为 8 MiB。源文件中的 YAML 不经过解析再序列化；编辑器保留 BOM 和统一 CRLF/CR 换行，无内容修改时保留原始内容。修改混合换行文件时统一为 LF。

后端拒绝隐藏路径、目录越界、非 Markdown 文件、符号链接目标/父目录及跨站写入请求。接口统一迁入密码登录后台，上表接口需加 `/admin` 前缀，旧根接口关闭。HTTPS Cookie 自动适配连接。

## 保存与冲突

进程内写操作串行执行。保存先读取当前文件并校验 revision，完成同目录隐藏临时文件写入和 Sync 后，再检查内容版本和文件身份；通过后用原子重命名替换。保留已有文件的普通权限位，拒绝改写没有写权限位的笔记。新文件通过完整临时文件的排他硬链接创建，存在同名文件时返回 409，不使用覆盖式重命名。正常成功和失败路径都会清理临时文件。

预览和 GET 请求不会写文件。成功保存后，目录刷新，图谱缓存失效，下一次打开图谱会重新索引。

外部版本变化时保留草稿，提示冲突，可查看服务器版本或复制草稿。界面没有强制覆盖路径。切换笔记、关闭标签页、切换图谱、刷新目录或退出编辑时，未保存草稿会提示“继续编辑 / 放弃修改 / 保存并继续”；保存失败不会继续导航。关闭或刷新整个页面使用浏览器的原生离开提醒，浏览器可能根据用户交互策略决定是否显示。

这是乐观版本检测，不是跨进程文件锁或文件系统原子 CAS。虽然在替换前再次核对，仍应避免在同一瞬间用 Obsidian 和 Web 同时保存；也不应同时启动多个可写服务操作同一目录。新文件创建要求文件系统支持同目录硬链接，当前在 Linux 本地文件系统验证。

## Git 与离线边界

Git 仓库自动启用远端版本校验、手动快进拉取、网页保存后提交推送；普通目录直接本地保存。离线或版本不一致时拒绝进入编辑/保存。文件已落盘但 Git 后续失败时明确展示警告并更新 revision，不回滚正文。配置与恢复方式见 [后台与 Git 同步](admin-git.md)。

浏览器报告离线时，编辑和保存按钮暂停，已有草稿保留在当前页面。服务无法连接或保存请求失败时，不会标记成功。草稿不写 localStorage、IndexedDB 或其他浏览器持久存储，页面关闭后不能自动恢复。没有自动保存或持久版本历史。

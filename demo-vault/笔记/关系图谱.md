# 关系图谱

图谱不是另一份需要维护的文档。它是 [[双向链接]] 的可视化投影。

## 从文件到节点

一篇笔记是一个节点，指向另一篇笔记的链接是一条有方向的连接。多个链接会聚合，指向章节和块的链接仍然归属原来的文件。

## 全库与局部

左侧工具栏的图谱按钮显示全库；阅读笔记时，顶部工具栏的图谱按钮显示当前笔记的入链和出链邻居。

你可以显示或隐藏未创建笔记、孤立笔记、附件和标签，也可以拖动节点、缩放平移，或点击节点继续阅读。

## 文件仍然属于你

图谱不会修改任何笔记，也不会执行 Git 操作。更新本地文件后，点击「重新索引本地目录」即可。
